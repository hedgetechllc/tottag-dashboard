The TotTag Helper is installed

Reload the TotTag dashboard. It should now show the helper as connected. When macOS asks whether the TotTag Helper may use Bluetooth, allow it; the setting is under System Settings > Privacy & Security > Bluetooth.

To check the installation from Terminal:
"/Library/Application Support/TotTag/TotTag Helper.app/Contents/MacOS/tottag-helper" doctor

To remove it:
sudo "/Library/Application Support/TotTag/TotTag Helper.app/Contents/MacOS/tottag-helper" uninstall --system
"/Library/Application Support/TotTag/TotTag Helper.app/Contents/MacOS/tottag-helper" uninstall
sudo rm -rf "/Library/Application Support/TotTag"
sudo pkgutil --forget net.tottag.helper
