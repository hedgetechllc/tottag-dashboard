TotTag Helper

The TotTag dashboard uses this helper to reach TotTags directly: it finds tags nearby over Bluetooth, so several can be picked at once from the dashboard's own list, and lists the tags plugged in over USB.

It installs one program, TotTag Helper, in /Library/Application Support/TotTag, and registers it with Chrome, Edge, Chromium, Brave, Vivaldi, Opera, and Arc. It runs only while the dashboard is open and asks for it. The first time it uses Bluetooth, macOS asks whether the TotTag Helper may.

You also need the TotTag Helper browser extension.
